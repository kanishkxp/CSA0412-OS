$ ./parity_demo
RAID 5: disk holding D2 failed -> rebuilt from parity: OK (identical to the original block)
RAID 6: disks holding D1 and D3 failed together -> rebuilt from P and Q: OK (both blocks identical to the originals)

CPU time to compute the parity of one stripe (4 x 4 KB data blocks):
  RAID 5 (P = XOR)         :      324 ns
  RAID 6 (P and Q)         :    13682 ns   (42.2 x more CPU work)

I/O needed to update ONE data block (small write):
  RAID 5: read old data, read old P, write new data, write new P                   = 4 disk I/Os
  RAID 6: read old data, read old P, read old Q, write new data, write new P and Q = 6 disk I/Os
  RAID 10: write the block to both disks of the mirror                              = 2 disk writes
  A disk I/O takes about 100 us (SSD) to 8,000 us (hard disk) so the parity CPU time of 13682 ns is small next to the extra I/O.
